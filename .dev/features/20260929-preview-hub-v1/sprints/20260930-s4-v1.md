## Goal and scope

- Outcome: the owner opens `https://preview-hub.cafitac.com` (behind Cloudflare Access), picks main, a branch or an open PR per service, creates an environment that opens at `https://phub-<env>.cafitac.com` (frontend at `/`, backend under `/_svc/api`), sees and deletes environments; `pr-<n>` refs work in CLI, bot and dashboard; referenced PRs get one cross-link comment each; everything stays free and inside the `preview-hub` VM.
- Target user: the owner (cafitac).
- Hypothesis: one origin per environment plus hub-side Access JWT verification gives safe public access through an outbound-only tunnel without any Cloudflare token or paid feature.
- Non-goals: per-environment DNS records or Cloudflare API calls, Access service tokens for automation (O4 deferred), multi-user roles, ai-qa, k3d/cloud runners, auto-update of environments when a PR head moves, any Earlypay code or configuration.
